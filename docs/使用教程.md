# SDVX 特效精简 v0.4.1：深黑底色修复使用教程

## 0.4.0 用户先看这里

上一版已收到「实机背景没有变深黑」的反馈。检查资源发现，背景动画自带独立的 AFP 底色，上一版的纯黑纹理与几何精简没有覆盖这层。0.4.1 补充 300 个背景动画底色覆盖，仅将已有底色的 RGB 改为黑色，保留透明度和时间线；修复效果仍待实机复测。

GitHub 同一预览发布页的下载包已覆盖为修复构建。重新下载、解压到新文件夹，确认窗口标题包含 `0.4.1`。退出游戏和启动器，打开修复版读取旧模式，再点击「应用当前选择」并确认。工具会自动补齐旧版缺少的底色覆盖，即使开关未变化也能升级，无需手工删除旧覆盖。

本工具通过可恢复的 IFS LayeredFS 覆盖，精简指定 SDVX 版本的背景和光效。v0.4 新增深黑背景纹理和 USC 深黑预设，并采用深色界面。

这是实验预览版，已完成资源格式、覆盖生成与恢复测试，尚未实机进歌验证。右侧轨道画面是示意图。SDVX 的 HUD 布局、镜头、Live2D 与脚本行为仍沿用原版，不能保证所有场景完全纯黑，也没有实测帧率提升数据。

## 1. 下载与准备

1. 在 [GitHub Releases](https://github.com/infinitytom/sdvx-effects-remover/releases) 下载 v0.4 的 Windows x64 ZIP，解压到普通文件夹。
2. 双击 `SDVX特效精简-USC深黑.exe`。需要 .NET 8 Windows Desktop Runtime；若系统提示缺少运行时，安装对应的 Windows x64 Desktop Runtime 后重试。运行成品不需要 Python 或 .NET SDK。
3. 退出游戏和 LAZY 启动器，也退出旧版特效精简工具。应用过程中不要启动游戏。

只支持 DLL 标识 `KFC-6aa256e6_7ad708` 和与规则匹配的原始资源。文件夹名称不能用于判断游戏版本。需要游戏现有配置中已启用 `ifs_hook.dll`；工具不会代替你安装游戏或注入组件。

## 2. 选择游戏目录

1. 打开默认的「画面精简」页，点击「浏览…」。
2. 选择含 `contents` 的 LAZY_KFC 根目录，不要选择 `contents` 本身。
3. 点击「读取模式」。工具会读取实际启用的各组覆盖，并记住所选路径；读取不会启用精简。

目录结构示例：

```text
LAZY_KFC/                 ← 选择这一层
  contents/
    data/
    modules/soundvoltex.dll
    lazy/spicetools.xml
    lazy/spicetools_patch_manager.json
    spice64.exe
```

无法读取时，点击「详细信息」查看缺少的文件或版本提示。不要通过改名、修改校验信息等方式强行绕过检查。

## 3. 应用 USC 深黑预设

1. 点击「USC 深黑」。该预设会选择隐藏舞台、深黑背景、减少旋钮尘粒、收敛轨道泛光和隐藏动态装饰。
2. 检查「隐藏判定与演出」保持关闭。USC 预设保留判定文字、EARLY/LATE 和连击反馈。
3. 点击「应用当前选择」，核对更改预览后确认。
4. 等待窗口底部提示保存完成。首次生成会核对原资源并创建大量覆盖文件，需要一些时间。
5. 通过原来的启动器进入游戏，下次启动生效。用同一首歌、同一难度检查背景、命中反馈和必要提示。

第一次使用也可以只开启一组并应用，确认游戏稳定后逐组增加。选择预设或切换开关只是待应用选择；工具不会自动把右侧示意图应用到游戏。

### 三个预设的区别

| 预设 | 选择结果 | 是否立即写入游戏 |
| --- | --- | --- |
| USC 深黑 | 开启前五项，保留判定与演出显示 | 否，需点击「应用当前选择」 |
| 仅留命中 | 开启全部六项，也隐藏判定文字及通关/失败演出 | 否，需点击「应用当前选择」 |
| 原版 | 取消全部六项 | 否，需点击「应用当前选择」 |

### 六个独立开关

| 界面开关 | 作用与保留内容 |
| --- | --- |
| 隐藏舞台背景 | 隐藏已识别的舞台、人物背景和背景粒子几何绘制。 |
| 深黑背景 | 同时处理 4302 张背景纹理和 300 个 AFP 已有底色；AFP 只改 RGB，保留透明度，不给原本透明的粒子动画新增不透明底色。建议配合隐藏舞台使用。 |
| 减少旋钮尘粒 | 精简指定旋钮尘粒；保留按键命中闪光、长按反馈和按键光柱。 |
| 收敛轨道泛光 | 减少指定轨道反光与 HUD 泛光；保留轨道、判定线和读谱信息。 |
| 隐藏动态装饰 | 精简旋钮周边光效、连击光束和指定 HUD 动态装饰；保留旋钮定位、血条、分数和连击数字。 |
| 隐藏判定与演出 | 隐藏可识别的 CRITICAL/ERROR、EARLY/LATE、CHAIN 字样和通关/失败、PUC/UC 演出；不改变判定逻辑、分数和通关结果。 |

## 4. 恢复原版与从旧版升级

### 恢复 v0.4 的画面覆盖

退出游戏及启动器，点击底部「恢复原版」，核对预览后确认。这个按钮会直接进入恢复应用流程，停用包括深黑背景在内的全部六组覆盖。之后正常启动游戏即可。

若只想恢复某一组，关闭对应开关，再点击「应用当前选择」。例如，只恢复判定文字时关闭「隐藏判定与演出」，其他精简项可以继续保留。

画面恢复不改变「启动设置」页的设置，也不会删除其他模组。

### 从 v0.3 绘制修正版升级

退出旧工具，使用 v0.4.1 读取同一游戏目录即可。既有五组几何规则保持不变，沿用 `effects-v2` 备份；新增的深黑背景默认按实际状态读取，需要主动选择并应用。v0.4.0 用户的底色修复升级步骤见本文开头。

### 更早的清零版本

早期清零绘制计数的方法可能触发 `afpu_render_draw_geo` 断言。若提示旧版覆盖版本不匹配，先使用「停用旧版覆盖」，再读取并选择新版模式。遇到文件被手工修改或目录不属于本工具的提示时，先保留现状检查，不要把旧文件复制回 `data_mods`。

## 5. 启动设置

右上角「启动设置」单独管理启动配置，与画面覆盖分别应用。

1. 退出游戏和 LAZY 启动器，点击「读取设置」。
2. 需要时选择「轻量预设」：减少 AVS 游戏日志、关闭副屏强制刷新、保留 Spice 叠加界面，并保持帧率设置原样。
3. 点击「预览并应用」，核对后保存，下次启动生效。

| 设置 | 使用说明 |
| --- | --- |
| 副屏强制刷新 | 副屏在全屏模式下不更新时可启用；关闭后副屏冻结，应恢复开启。 |
| 减少游戏日志 | 仅保留 AVS 警告和错误，Spice 日志仍保留。 |
| 保留 Spice 叠加界面 | 建议依赖 F9、FPS 显示或副屏叠加触控入口的用户保留开启。 |
| 保持当前 / 60 FPS / 120 FPS | 选择帧率会同时设置游戏与音符帧率；游玩后检查音画同步。 |

需要撤销启动配置时，点击「恢复备份…」，进入对应时间文件夹并选择 `journal.json`。如果备份之后配置又被其他程序修改，工具会拒绝直接覆盖，避免丢失后续设置。

## 6. 常见问题

| 情况 | 处理办法 |
| --- | --- |
| 提示缺少 .NET | 安装 .NET 8 Windows Desktop Runtime x64；SDK 和普通 .NET Runtime 不能代替 Desktop Runtime。 |
| 不是支持的 LAZY_KFC 目录 | 重新选择含 `contents` 的根目录，按「详细信息」检查所缺文件。 |
| 原资源哈希或 DLL 标识不匹配 | 当前安装不符合本版规则。停止应用，使用匹配的规则或等待支持，不要覆盖原始 IFS。 |
| 未配置 `ifs_hook.dll` | 检查原启动器的 IFS Hook 注入设置；工具需要现有资源覆盖功能正常工作。 |
| 其他模组覆盖相同容器 | 检查提示的模组与资源目录，先自行处理冲突；不要直接删除不明模组。 |
| 切换开关后游戏没有变化 | 确认已点击「应用当前选择」并完成保存，退出后重新启动游戏；同时确认选择的是实际启动的游戏副本。 |
| 黑色背景仍有演出或角色 | 先确认窗口标题为 0.4.1 并已重新应用；「详细信息」应列出 300 个 AFP 动画底色。Live2D、脚本、镜头和未识别绘制仍不在完整覆盖范围内；若依旧不是深黑，请提供曲目和背景现象用于继续定位。 |
| 判定提示消失 | 关闭「隐藏判定与演出」再应用，或重新选择「USC 深黑」并应用。 |
| 生成过程中异常退出 | 重新打开并读取实际状态；需要时恢复原版。未完成的生成通常留在 `staging`，不要手动将其作为模组启用。 |
| 出现闪退或必要提示缺失 | 退出游戏后恢复原版，先确认原版稳定；提交问题时说明工具版本、游戏 DLL 标识、启用分组与复现步骤，日志先脱敏。 |

## 7. 覆盖与备份位置

原始 IFS、DLL、谱面和音频不会被改写。纯黑 PNG 由程序生成，不包含原游戏图像。

| 内容 | 相对于游戏根目录的位置 |
| --- | --- |
| 启用中的覆盖 | `contents/data_mods/zzzz_sdvx_smooth_*` |
| 停用后的 v2 覆盖 | `.sdvx-smooth/effects-v2/disabled` |
| 画面开关历史 | `.sdvx-smooth/effects-v2/history` |
| 尚未完成的生成 | `.sdvx-smooth/effects-v2/staging` |
| 启动设置备份 | `.sdvx-smooth/backups` |
| 旧版覆盖备份 | `.sdvx-smooth/effects-v1` |

六个界面开关对应 `background`、`black`、`hit`、`lane`、`extra`、`judgment` 和新增 `backdrop` 七个目录。其中深黑开关同时控制 `black` 与 `backdrop`，恢复原版会停用两者。升级游戏前建议先恢复原版，不要把旧版覆盖手动复制回新游戏。

## 8. 本版已完成的验证

- 22312 条几何规则的原始资源与修改结果校验，保持绘制计数和非顶点数据不变。
- 625 个命中、长按和旋钮定位资源保护条目保持不变。
- 4302 张深黑纹理的路径和尺寸与本机匹配 IFS 元数据逐项核对。
- 在临时合成游戏目录完整生成、验证、停用和重新启用全部深黑覆盖。
- 测试纯黑 PNG 的不透明 RGB `0,0,0`、单组恢复、文件被修改后的冲突保护和原资源保持不变。
- 独立使用原始 BSI 表解码全部背景 AFP，确认 300 个需要修复的底色仅 RGB 变黑，透明度、标志、时间线和 BSI 保持原值；不向透明动画新增底色。
- 验证旧版仅有纹理覆盖、开关选择没有变化时，修复版仍能补齐底色覆盖，并可恢复和重新启用；被修改的 AFP 覆盖会阻止整次恢复。

上一版已通过静态测试但实机背景仍未变黑，因此这些测试不代替实际歌曲稳定性、视觉效果或帧率测试。底色字段解释参考 [bemaniutils AFP 解析器](https://github.com/DragonMinded/bemaniutils/blob/master/bemani/format/afp/swf.py)。
